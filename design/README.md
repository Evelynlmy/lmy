# 邮轮预订系统 C端产品设计文档

## 项目概述

本文档为邮轮预订系统 C 端完整产品设计，覆盖用户从首页浏览到评价反馈的全链路体验。

## 文档目录

| 模块 | 文件路径 | 说明 |
|------|----------|------|
| 0. 全局规范 | `00-global-spec.md` | 设计原则、色彩/字体/间距规范 |
| 1. 首页 | `01-homepage/` | Banner、搜索入口、推荐模块 |
| 2. 搜索 | `02-search/` | 搜索条件、结果列表 |
| 3. 产品详情 | `03-product-detail/` | 行程、舱型、价格、政策 |
| 4. 选舱型 | `04-cabin-selection/` | 舱型对比、价格矩阵 |
| 5. 甲板图选房 | `05-deck-map/` | 可视化选房、房间属性 |
| 6. 下单支付 | `06-order-payment/` | 乘客信息、价格汇总、支付 |
| 7. 履约链路 | `07-fulfillment/` | 成团通知、行前提醒、登船 |
| 8. 评价反馈 | `08-review/` | 评价入口、评价内容、展示 |

## 用户旅程总览

```
首页浏览
   │
   ▼
搜索（条件筛选）
   │
   ▼
搜索结果列表
   │
   ▼
产品详情页
   │
   ▼
选舱型（舱位等级）
   │
   ▼
甲板图选房号（可视化选房）
   │
   ▼
填写乘客信息
   │
   ▼
价格确认 & 支付
   │
   ▼
成团通知（达到开团人数）
   │
   ▼
行前履约链路（提醒、登船、在船服务）
   │
   ▼
行程结束 → 评价反馈
```

## 核心设计目标

1. **转化率**：降低选房决策门槛，提升支付转化
2. **信任感**：价格透明、政策清晰、真实评价
3. **体验流畅**：关键路径步骤精简，减少信息过载
4. **履约感知**：从支付到上船全程有感知、有安全感
