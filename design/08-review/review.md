# 评价反馈设计文档

## 一、设计目标

评价体系是邮轮产品的核心信任建设机制：
1. **激励评价**：提高评价率（目标 > 30%）
2. **内容质量**：引导图文评价，避免无效短评
3. **真实可信**：仅限实际购买者评价，防刷
4. **帮助决策**：评价对后续用户有实质参考价值

---

## 二、评价触发时机

```
行程结束次日 → 推送评价提醒（Push + 站内消息）
下船后第3天  → 二次提醒（如未完成）
下船后第7天  → 最终提醒（含积分奖励说明）
下船后第15天 → 评价入口关闭（转为历史订单）
```

**Push 通知文案：**
```
🌊【邮轮出行】旅途已结束，留下您的精彩回忆
完成评价获得 200 积分 + 下次专属优惠券！
[立即评价 →]
```

## 六、评价管理（商家侧逻辑）

### 6.1 内容审核规则

| 规则 | 说明 |
|------|------|
| 实名校验 | 仅订单实际乘客可评价 |
| 内容过滤 | 违禁词/广告/个人信息自动过滤 |
| 图片审核 | AI初审+人工复核 |
| 评价时效 | 行程结束后15天内可提交 |
| 修改规则 | 评价提交后48小时内可修改一次 |
| 举报机制 | 用户可举报不实评价 |

## 七、评价反馈与改进闭环

```
用户评价 → 后台汇总分析
             │
             ├─ 低分预警 → 运营介入 → 主动联系用户
             │
             ├─ 共性问题 → 产品/供应链改进
             │
             └─ 好评精选 → 展示在首页/详情页
```

**低分处理流程（3星及以下）：**
```
用户提交差评
  ↓
系统自动识别，标记待处理
  ↓
客服24小时内主动联系用户
  ↓
了解具体问题，提供解决方案
  ↓
处理完成后，邀请用户修改评价
```
