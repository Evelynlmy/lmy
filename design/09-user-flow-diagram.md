## 二、关键分支流程

### 2.1 取消/退款分支

```
任意已确认状态
  │
  ▼
发起退款申请
  │
  ▼
展示退款金额（按退改政策计算）
  │
  ▼
用户确认 → 退款处理中 → 3-7天到账
  │
  ▼
退款完成通知
```

### 2.2 未登录用户流程

```
首页/搜索 → 未登录可浏览
  │
  ▼
点击预订 → 弹出登录/注册弹层
  │
  ▼
登录成功 → 回到预订流程（保留选择状态）
```

### 2.3 已收藏产品路径

```
收藏夹 → 点击产品 → 直接进入产品详情页
```

## 三、页面间参数传递

| 来源页 | 目标页 | 传递参数 |
|--------|--------|----------|
| 搜索结果 | 产品详情 | product_id, date, adults, children |
| 产品详情 | 选舱型 | product_id, date, adults, children |
| 选舱型 | 甲板图 | product_id, cabin_type, package_type, date |
| 甲板图 | 填写乘客信息 | product_id, room_id, cabin_type, package_type |
| 填写信息 | 价格确认 | order_draft（含所有信息） |
| 价格确认 | 支付 | order_id, amount |
| 支付 | 结果页 | order_id, status |

## 四、核心指标漏斗

```
首页访问 (100%)
    │ 搜索转化率
    ▼
搜索结果 (60%)
    │ 详情查看率
    ▼
产品详情 (35%)
    │ 选舱转化率
    ▼
选舱型页 (20%)
    │ 进入选房率
    ▼
甲板选房 (18%)
    │ 填表完成率
    ▼
乘客信息 (16%)
    │ 确认下单率
    ▼
确认页   (15%)
    │ 支付转化率
    ▼
支付成功 (12%)

优化重点：
- 详情→选舱：需降低价格焦虑（展示多价位）
- 选舱→填表：需降低信息填写门槛（导入历史）
- 填表→支付：需提升信任感（安全支付标识）
```
