# 产品详情页设计文档

## 一、页面定位

产品详情页是用户决策的核心页面，需要充分呈现：
- **行程信息**（靠港城市、日期、时长）
- **船舶信息**（船名、设施、照片）
- **舱型价格**（各舱型对比、价格矩阵）
- **预订政策**（退改规则、含不含项目）
- **真实评价**（评分、评价内容）

## 五、底部固定栏

```
┌────────────────────────────────┐
│  内舱 ¥5,999起/人  [2大0小 ▼]  │
│  [咨询客服]    [立即预订]       │
└────────────────────────────────┘
```

**逻辑说明：**
- 价格随人数选择动态变化
- 「立即预订」→ 进入选舱型页
- 「咨询客服」→ 打开在线客服

## 六、数据埋点

```
page_view: product_detail, product_id
image_gallery_view: product_id, image_index
section_view: product_id, section_name（行程/船舶/舱型/评价）
tab_click: product_id, tab_name
price_matrix_view: product_id
cabin_type_click: product_id, cabin_type
review_list_view: product_id
book_button_click: product_id, source（bottom_bar）
share_click: product_id
favorite_click: product_id, action（add/remove）
```
