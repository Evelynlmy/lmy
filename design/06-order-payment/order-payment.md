### 2.2 表单验证规则

| 字段 | 验证规则 |
|------|----------|
| 姓名拼音 | 仅字母，与证件一致 |
| 身份证号 | 18位，Luhn算法校验 |
| 护照号 | 字母+数字，有效期校验 |
| 手机号 | 国内11位/国际格式 |
| 出生日期 | 年龄需符合舱型要求 |
| 儿童年龄 | 2-11岁，需成人陪同 |

### 2.3 证件类型选项

- 中国大陆居民身份证
- 中国护照
- 港澳通行证
- 台湾居民来往大陆通行证
- 外国护照
- 其他有效证件

## 六、防重复提交机制

```
支付流程保障：
1. 支付按钮点击后立即禁用，显示loading
2. 服务端幂等性校验（同一订单15分钟内防重复）
3. 支付回调成功后才跳转成功页
4. 网络异常时查询订单状态而非重新发起
```
