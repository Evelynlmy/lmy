# 搜索页设计文档

## 一、页面定位

搜索是用户精准找到目标产品的核心路径，分为两个子页面：
1. **搜索条件页**：输入/选择出发港、日期、人数等条件
2. **搜索结果页**：展示匹配产品列表，支持筛选排序

---

## 四、搜索异常状态

| 状态 | 展示内容 |
|------|----------|
| 无结果 | 插画 + "暂无符合条件的邮轮" + 修改条件建议 |
| 加载中 | 卡片骨架屏（3张） |
| 加载更多 | 底部 loading 动效 |
| 网络错误 | 错误提示 + 重试按钮 |

## 五、数据埋点

```
search_condition_set: field_name, value
search_submit: all conditions combined
search_result_count: count, duration
result_card_impression: product_id, position
result_card_click: product_id, position
filter_apply: filter_type, filter_value
sort_change: sort_type
```
