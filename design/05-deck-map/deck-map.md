# 甲板图选房号设计文档

## 一、页面定位

甲板图选房是邮轮预订的核心差异化功能，让用户可视化地选择具体房间：
- **位置感知**：了解房间在船上的具体位置（船头/船中/船尾）
- **楼层感知**：了解所在甲板层数（高层海景更好）
- **属性透明**：清晰展示每个房间的具体属性
- **比价选房**：同舱型内不同位置的价格差异

## 四、房间属性详情

### 4.1 位置分类

| 位置 | 特点 | 建议人群 |
|------|------|----------|
| 船头 | 风浪感明显，视野开阔 | 年轻人、探险者 |
| 船中 | 最稳，噪音最小 | 容易晕船、老年人 |
| 船尾 | 可看浪花，发动机稍有噪音 | 喜欢特别体验 |
| 左舷（港侧）| 停靠时景色好 | 观景优先 |
| 右舷（海侧）| 离岸时景色好 | 海景优先 |

## 五、选房交互逻辑

### 5.1 交互流程

```
进入甲板图页
  │
  ▼
默认展示推荐甲板层（如第9层）
  │
  ▼
用户切换甲板层
  │
  ▼
点击具体房间
  │
  ▼
弹出房间信息卡片（底部弹层）
  │
  ├─ 点击[确认选择] → 进入填写乘客信息
  │
  └─ 点击其他房间 → 更新底部卡片
```

### 5.2 系统推荐

首次进入时，系统自动推荐并高亮显示最优房间：

```
┌────────────────────────────────┐
│  💡 为您推荐：9层船中阳台舱    │
│  9012号房                      │
│  · 船中位置，平稳性最好        │
│  · 第9层，视野开阔             │
│  · ¥12,888/人起                │
│               [查看推荐房间]   │
└────────────────────────────────┘
```

### 5.3 手势交互

| 手势 | 功能 |
|------|------|
| 单指拖动 | 平移地图 |
| 双指缩放 | 缩放地图 |
| 单击房间 | 查看房间信息 |
| 双击 | 放大中心区域 |
| 点击空白处 | 收起房间信息卡片 |

## 六、已售/锁定状态

```
状态说明：
□ 白色底色    可选房间
■ 蓝色填充    已选中（当前用户）
░ 灰色填充    已售出（不可选）
▒ 黄色填充    锁定中（其他用户正在看）
× 叉号       不可售房间（船员房/设备间）
```

**并发锁定机制：**
- 用户点击房间后，服务端锁定该房间 10 分钟
- 锁定状态对其他用户显示为「锁定中」
- 10 分钟内未完成支付，自动释放
