# 首页设计文档

## 一、页面定位

首页是用户进入 App 的第一触点，核心目标：
1. **激发欲望**：精选内容触达用户兴趣
2. **快速入口**：搜索直达，降低决策成本
3. **促销转化**：限时优惠、热门路线曝光

## 三、模块详细设计

### 3.1 搜索入口

**设计要点：**
- 固定在顶部（滚动时保持可见）
- 默认展示上次搜索条件（已登录用户）
- 三个快选标签：出发港、日期、人数
- 点击任意区域 → 进入搜索页

**交互逻辑：**
```
点击搜索框 → 展开全屏搜索页
点击[出发港] → 弹出出发港选择弹层
点击[日期]  → 弹出日历组件
点击[人数]  → 弹出舱位/人数选择器
```

**默认文案：**
- 搜索框：「搜索目的地、邮轮名称、港口」
- 出发港：「出发港」
- 日期：「出发日期」
- 人数：「2大0小」

---

### 3.2 Banner 轮播

| 属性 | 规格 |
|------|------|
| 宽高比 | 16:7 |
| 自动播放 | 4秒/张 |
| 圆角 | 12px |
| 内容 | 活动/路线/船公司合作 |
| 埋点 | 曝光率、点击率、点击位置 |

**Banner 内容结构：**
```
┌────────────────────────────┐
│  [背景大图：船/海/港口]     │
│                            │
│  主标题（促销语）           │
│  副标题（路线+时间）        │
│         [立即查看 →]       │
└────────────────────────────┘
```

---

### 3.3 快捷分类导航

- 横向滚动，每屏显示 5 个，其余滑动查看
- 图标 + 文字，图标使用目的地代表性建筑/景点
- 点击 → 带目的地参数进入搜索结果页

---

### 3.4 限时特惠

**设计逻辑：**
- 服务端控制倒计时，客户端展示
- 产品卡片（小型）：2列横排，可横滑
- 角标：「已售X%」制造紧迫感

## 四、首页交互状态

| 状态 | 处理方式 |
|------|----------|
| 加载中 | 骨架屏，各模块独立加载 |
| 网络错误 | 显示缓存数据 + 刷新提示 |
| 已登录 | 展示个性化推荐 |
| 未登录 | 展示热门/默认内容，引导注册 |
| 新用户 | 首页弹出引导蒙层（新手优惠） |

---

## 五、性能要求

| 指标 | 目标 |
|------|------|
| 首屏加载时间 | < 2秒（4G网络） |
| 图片懒加载 | 视口外图片延迟加载 |
| Banner图预加载 | 第一张图优先加载 |
| 接口响应 | 首页接口 < 500ms |
