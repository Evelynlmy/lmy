# 全局设计规范

## 一、设计原则

| 原则 | 说明 |
|------|------|
| 清晰 | 信息层级分明，用户一眼看懂核心内容 |
| 高效 | 关键操作触手可及，减少无效跳转 |
| 信任 | 价格透明、政策明确、评价真实 |
| 愉悦 | 视觉精致，符合邮轮「高端度假」调性 |

---

## 二、色彩规范

### 主色调

```
主色 Primary     #0057A8   深海蓝（信任感、专业感）
辅色 Secondary   #00A3C4   海洋青（活力、清新）
强调 Accent      #F5A623   金色（促销、高亮）
```

### 功能色

```
成功 Success     #27AE60
警告 Warning     #F5A623
错误 Error       #EB5757
信息 Info        #2F80ED
```

### 中性色

```
标题文字        #1A1A2E
正文文字        #333333
次要文字        #666666
辅助文字        #999999
占位文字        #CCCCCC
分割线          #EBEBEB
页面背景        #F7F8FA
卡片背景        #FFFFFF
```

---

## 三、字体规范

```
主字体（中文）：PingFang SC / Noto Sans SC
主字体（数字）：DIN Alternate（价格数字专用）

字号体系：
  页面大标题      24px  Bold
  模块标题        18px  SemiBold
  卡片标题        16px  Medium
  正文内容        14px  Regular
  辅助说明        12px  Regular
  标签/角标       11px  Medium
```

---

## 四、间距规范

```
页面边距         16px（左右）
卡片内边距       16px
模块间距         20px
列表项间距       12px
图标与文字间距   6px
```

---

## 五、圆角规范

```
大卡片（产品卡片）   12px
小卡片/弹窗          8px
按钮                 8px
标签/徽章            4px
头像                 50%（圆形）
```

---

## 六、按钮规范

| 类型 | 尺寸 | 颜色 | 使用场景 |
|------|------|------|----------|
| 主按钮 | 高48px 全宽 | 主色 #0057A8 | 最核心操作（立即预订、确认支付） |
| 次级按钮 | 高40px | 边框主色 | 次要操作（查看详情、加入收藏） |
| 文字按钮 | 高32px | 主色文字 | 弱操作（查看全部、展开更多） |
| 危险按钮 | 高40px | #EB5757 | 取消订单 |
| 禁用状态 | — | #CCCCCC | 不可操作时 |

---

## 七、图标规范

- 规格：24×24（标准），20×20（紧凑），16×16（内嵌）
- 风格：线性图标，线条粗细 1.5px
- 库：优先使用统一图标库，保持风格一致

---

## 八、导航规范

### 底部导航（Tab Bar）
```
[首页]  [搜索]  [订单]  [我的]
```

### 顶部导航（Navigation Bar）
- 高度：44px（iOS）/ 56px（Android）
- 包含：返回、页面标题、右侧操作（分享/收藏）

---

## 九、加载与空状态

| 场景 | 方案 |
|------|------|
| 列表加载 | 骨架屏（Skeleton Screen） |
| 图片加载 | 渐进式加载 + 占位符 |
| 空结果 | 插画 + 文案 + 引导按钮 |
| 网络错误 | 错误图 + 重试按钮 |
| 操作中 | 按钮 loading 态，禁止重复点击 |

---

## 十、埋点规范（数据追踪）

所有关键页面和操作需预埋以下数据点：

```
页面维度：page_view（页面名、来源渠道、用户ID）
点击维度：element_click（元素名、位置、页面名）
转化维度：conversion（步骤名、成功/失败、耗时）
曝光维度：impression（卡片ID、位置、曝光时长）
```
