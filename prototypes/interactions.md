# 交互设计规范文档

## 一、核心交互原则

| 原则 | 说明 |
|------|------|
| 即时反馈 | 任何点击在 100ms 内有视觉反馈 |
| 渐进揭示 | 复杂信息分步骤展示，降低认知负担 |
| 可逆操作 | 关键步骤提供返回/撤销能力 |
| 状态可见 | 当前步骤、加载状态、操作结果随时可见 |

---

## 二、动效规范

### 页面切换
```
进入动效：新页面从右侧滑入 (translateX: 100% → 0)
退出动效：旧页面向左滑出 (translateX: 0 → -100%)
时长：300ms
缓动：cubic-bezier(0.4, 0, 0.2, 1)
```

### 弹层/面板
```
底部弹层：从下方弹出 (translateY: 100% → 0)
遮罩：透明度渐变 (opacity: 0 → 0.5)
时长：250ms
缓动：ease-out
```

### Toast 通知
```
出现：从顶部下滑 + 淡入
消失：淡出
停留时长：2000ms
```

### 微交互
```
按钮点击：scale(0.97) + opacity(0.85), 150ms
星级评分：逐颗填充动画，50ms 间隔
进度条：从 0 到目标值，500ms ease-out
倒计时：数字变化时轻微 scale(1.1) 抖动
```

## 三、手势交互

| 手势 | 触发条件 | 行为 |
|------|----------|------|
| 左滑 | 页面内容区 | 进入下一步（非主流程，提示） |
| 右滑 | 屏幕左边缘 30px 内 | 返回上一页（iOS 系统手势） |
| 下拉 | 列表顶部 | 刷新内容 |
| 上滑 | 底部弹层 | 展开完整内容 |
| 长按 | 产品卡片 | 弹出快速操作菜单（收藏/分享） |
| 双指缩放 | 甲板图区域 | 放大/缩小地图 |

| Tab 切换 | 点击 | 页面切换动效 |

### 甲板图选房

| 提交评价 | 点击 | loading → 成功弹窗（含积分动画） |

## 五、表单交互

### 输入框状态
```
默认态：灰色边框 #EBEBEB
聚焦态：蓝色边框 #0057A8 + 外发光
错误态：红色边框 #EB5757 + 错误文案
成功态：绿色边框 #27AE60 + ✓ 图标
```

### 错误提示时机
- 失去焦点（onBlur）时触发验证
- 不在输入过程中打断用户
- 提交时全量校验，滚动到第一个错误

### 证件号码输入
- 身份证：每4位自动加空格（展示用）
- 实时计算并展示年龄（"1990-01-01 → 36岁"）
- 有效期临近警告（护照距到期<6个月）

## 六、空状态与异常处理

| 场景 | 展示 | 操作 |
|------|------|------|
| 搜索无结果 | 🔍 + "没找到符合条件的邮轮" | 修改筛选条件 |
| 网络超时 | 📡 + "网络连接失败" | 重试按钮 |
| 房间全售 | 😔 + "该舱型已售罄" | 换日期/换舱型 |
| 支付失败 | ❌ + 失败原因 | 重新支付/换方式 |
| 订单过期 | ⏰ + "订单已超时取消" | 重新预订 |

---

## 七、无障碍设计

- 所有可点击元素最小尺寸 44×44px
- 颜色区分同时提供图标/文字辅助
- 表单标签与输入框明确关联
- 重要提示不仅用颜色区分
- 支持系统字体大小设置
